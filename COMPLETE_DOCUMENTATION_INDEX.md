## 📞 Support & Troubleshooting

### Common Issues

**Q: Sequence doesn't play?**
A: Check DevTools Console. GSAP timeline should fire. See TESTING_GUIDE.md → "Debug Checklist"

**Q: Timing is off?**
A: GSAP timeline is exact. If timing feels off, check CPU load or system performance. Use DevTools Performance tab to profile.

**Q: Blur not working?**
A: Blur quality varies by browser. Chrome best. Firefox excellent. Safari may simplify on older devices (acceptable fallback).

**Q: Revisit doesn't skip?**
A: Check sessionStorage enabled. Try private window for fresh test. See TESTING_GUIDE.md → "Common Issues & Fixes"

**Q: Text encoding looks wrong?**
A: Check glyph set: `ABCDEFGHIJKLMNOPQRSTUVWXYZ0123456789@#$%&`. No brackets or symbols.

### Debug Steps
1. Open DevTools (F12)
2. Console → Check for errors
3. Performance tab → Check FPS
4. Application → SessionStorage → Check flag
5. See TESTING_GUIDE.md → "Debug Checklist"
