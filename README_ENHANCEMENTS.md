## 🎓 HOW IT WORKS

### Text Reveals
1. **User scrolls** section into viewport
2. **ScrollTrigger detects** when `data-reveal-*` element is at trigger point
3. **Hook splits** text into spans/divs based on strategy
4. **GSAP animates** opacity and transform with stagger
5. **Text appears** with chosen animation effect
6. **User continues** scrolling to next section

### Energy Beams
1. **SectionInterconnections** component renders on mount
2. **Finds all sections** by ID (hero, about, skills, etc.)
3. **Creates SVG beams** between sections
4. **pathLength animates** 0→1 continuously
5. **Opacity responds** to scroll position
6. **Signals pulse** at connection points

### IMAX Effects
1. **CSS utility classes** available globally
2. **Applied to sections** for depth perception
3. **Keyframe animations** loop continuously
4. **GPU-accelerated** via transform properties
5. **Mobile reduced** if performance needed
